# ชุดข้อความตอบลูกค้าสำหรับแอดมิน iPrint

ใช้ข้อความจาก `iprint-admin-reply-templates.json` เป็นข้อความตอบกลับสำเร็จรูป โดยแทนค่าที่อยู่ในวงเล็บปีกกาก่อนส่ง เช่น `{customer_name}`, `{order_id}` และ `{due_date}`

## ลำดับแนะนำ

1. เริ่มด้วย `/hello` เมื่อแอดมินเข้ารับช่วงจากบอต
2. ใช้ `/ขอบรีฟ` หรือ `/ข้อมูลขาด` เพื่อเก็บรายละเอียดให้ครบ
3. ใช้ `/รับไฟล์` และ `/แก้ไฟล์` ในขั้นตอนตรวจอาร์ตเวิร์ก
4. ใช้ `/เสนอราคา` เมื่อราคาและระยะเวลาผ่านการตรวจจากทีมแล้ว
5. ใช้ `/รอชำระ`, `/รับยอด` และ `/ยืนยันแบบ` ก่อนเริ่มผลิต
6. ใช้ `/กำลังผลิต`, `/รับสินค้า` หรือ `/จัดส่ง` เพื่อติดตามงาน
7. ใช้ `/ปิดงาน` หลังลูกค้าได้รับสินค้าและไม่มีเรื่องค้าง

## หลักการตอบ

- เรียกลูกค้าด้วยชื่อเมื่อทราบชื่อแล้ว
- หนึ่งข้อความควรมีหนึ่งประเด็นและหนึ่งขั้นตอนถัดไป
- ตรวจราคา วันส่ง เลขออร์เดอร์ และเลขพัสดุก่อนส่งทุกครั้ง
- หลีกเลี่ยงการรับปากวันเสร็จก่อนตรวจคิวผลิต
- เมื่อรับช่วงจากบอต ให้บอกชัดว่าแอดมินกำลังตรวจข้อมูลเพื่อไม่ให้ลูกค้าส่งซ้ำ
