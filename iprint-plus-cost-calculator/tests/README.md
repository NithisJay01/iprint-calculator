# iPrint Logic Tests

เปิด `tests/logic-test.html` ผ่านเว็บเซิร์ฟเวอร์เดียวกับโปรเจกต์ แล้วกด **รันทดสอบทั้งหมด**

ตรวจ logic การจัดหมวดบริการและการเลือก CSS/WebGL renderer โดยไม่เปิดเบราว์เซอร์:

```bash
node tests/ui-logic-node-test.mjs
```

ชุดทดสอบทำงานกับ `index.html` จริงและครอบคลุมการเริ่มระบบ, สูตรจำนวนแผ่นและ Gap ระหว่างชิ้นงาน, ราคาขาย, การเปลี่ยนจำนวน, วัสดุ, บริการ, ภาพงานและ Ref ชั่วคราว (สูงสุด 3 ภาพ), การลากภาพลง Preview, Preview ที่จัดกึ่งกลาง, การปรับ Bleed, Deadline รายชิ้นงาน, ตะกร้าหลายรายการ, หน้าติดตาม Workflow, ภาพสรุปบรีฟงาน, คำอธิบายสำหรับกราฟิก, ข้อมูล Ticket และ Preview ใบเสนอราคา/VAT โดยไม่กดปุ่มบันทึกหรือพิมพ์ จึงไม่มีการเขียนข้อมูลไปยัง Notion.
