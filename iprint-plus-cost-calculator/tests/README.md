# iPrint Logic Tests

เปิด `tests/logic-test.html` ผ่านเว็บเซิร์ฟเวอร์เดียวกับโปรเจกต์ แล้วกด **รันทดสอบทั้งหมด**

ชุดทดสอบทำงานกับ `index.html` จริงและครอบคลุมการเริ่มระบบ, สูตรจำนวนแผ่นและ Gap ระหว่างชิ้นงาน, ราคาขาย, การเปลี่ยนจำนวน, วัสดุ, บริการ, ภาพงานและ Ref ชั่วคราว (สูงสุด 3 ภาพ), การลากภาพลง Preview, Preview ที่จัดกึ่งกลาง, การปรับ Bleed, ภาพสรุปบรีฟงาน, คำอธิบายสำหรับกราฟิก, ข้อมูล Ticket และ Preview ใบเสนอราคา/VAT โดยไม่กดปุ่มบันทึกหรือพิมพ์ จึงไม่มีการเขียนข้อมูลไปยัง Notion.
