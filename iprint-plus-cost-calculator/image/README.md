# ไฟล์ภาพและไอคอนของ iPrint UI

หากต้องการเปลี่ยนไอคอน ให้ Replace ไฟล์โดยคงชื่อเดิมไว้ หน้าเว็บจะใช้ภาพใหม่โดยไม่ต้องแก้ HTML หรือ JavaScript

| File | จุดที่ใช้งาน |
| --- | --- |
| `iprint-logo.svg` | โลโก้หน้า Login และ Header |
| `cart.svg` | ตะกร้าบน Header |
| `settings.svg` | ปุ่มตั้งค่า API |
| `api.svg` | ภาพหัวข้อในแผงตั้งค่า API |
| `service-laser.svg` | ภาพบริการ Laser |
| `service-inkjet.svg` | ภาพบริการ Inkjet |
| `upload.svg` | ปุ่มอัปโหลด Artwork |
| `rotate.svg` | ปุ่มหมุน Artwork และกระดาษ |
| `close.svg` | ปุ่มปิด Modal/Sheet และปุ่มลบ |
| `arrow-left.svg` | ปุ่มกลับ/ก่อนหน้า |
| `arrow-right.svg` | ปุ่มถัดไปบนพื้นสว่าง |
| `arrow-right-light.svg` | ปุ่มถัดไปบนพื้นเข้ม |
| `plus.svg` | ปุ่มเพิ่ม |
| `chevron-down.svg` | ลูกศรของ Select |

แนะนำให้ใช้ SVG และคง `viewBox` เดิม หากเปลี่ยนเป็น PNG ต้องแก้นามสกุลไฟล์ใน HTML/CSS ด้วย
