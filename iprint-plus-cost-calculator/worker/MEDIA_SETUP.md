# อัปโหลดรูปแกลเลอรี่ของเซต (Cloudflare R2)

หน้า Set Studio (`/pricing/`) อัปโหลดรูปตัวอย่างงานของแต่ละเซตได้สูงสุด 5 รูป แล้วหน้าสั่งซื้อแสดงเป็นแกลเลอรี่ใต้ภาพหลัก

ไฟล์รูปเก็บใน **R2 bucket** ของ Cloudflare ผ่าน Worker เพราะตัวการตั้งค่าเป็นข้อมูลก้อนเล็ก (ไม่เกิน 150 KB) เก็บรูปไม่ได้ ในการตั้งค่าเก็บแค่ลิงก์ของรูป

```
Studio: เลือกไฟล์ → ย่อภาพในเบราว์เซอร์ (ด้านยาวไม่เกิน 1600 px, WebP)
        → POST /staff/uploads (ต้องมี API Key พนักงาน) → R2
        → ได้ลิงก์ https://<worker>/media/gallery/<uuid>.webp เก็บในเซต
หน้าลูกค้า: GET /media/gallery/<uuid>.webp (สาธารณะ แคชได้ 1 ปี)
```

ถ้ายังไม่ตั้งค่า R2 ระบบอื่นทำงานปกติ ปุ่มอัปโหลดจะแจ้งว่ายังไม่ได้ตั้งค่า และเพิ่มรูปด้วย **ลิงก์รูป** แทนได้ทันที

## ตั้งค่า (ครั้งเดียว)

1. เปิดใช้ R2 ในบัญชี Cloudflare (Dashboard → R2) ถ้ายังไม่เคยเปิด Cloudflare อาจขอบัตรเครดิตเพื่อยืนยันบัญชี แต่โควตาฟรีเพียงพอมาก (รูปละไม่กี่ร้อย KB)
2. สร้าง bucket:
   ```
   cd iprint-plus-cost-calculator/worker
   npx wrangler r2 bucket create iprint-media
   ```
3. ใน `wrangler.toml` เอา `#` หน้าบล็อก `[[r2_buckets]]` ออก (ท้ายไฟล์):
   ```
   [[r2_buckets]]
   binding = "MEDIA"
   bucket_name = "iprint-media"
   ```
4. Deploy: `npx wrangler deploy`
5. ลองอัปโหลดรูปจากหน้า Studio (ต้องเปิดบนเว็บจริงและกรอก API Key)

## กฎที่ระบบบังคับ

- อัปโหลดได้เฉพาะพนักงานที่มี `X-API-Key` (ไม่มี key = 401 และไม่แตะ R2)
- รับเฉพาะ **JPEG, PNG, WebP** ตรวจจากไบต์แรกของไฟล์ ไม่เชื่อชื่อไฟล์หรือ Content-Type ที่ส่งมา และ **ไม่รับ SVG** เพราะ SVG ฝังสคริปต์ได้
- ไฟล์ใหญ่สุด 3 MB (เบราว์เซอร์ย่อให้ก่อนอยู่แล้ว ปกติไม่กี่ร้อย KB)
- ชื่อไฟล์ใน R2 สุ่มใหม่ทุกครั้ง (`gallery/<uuid>.<นามสกุล>`) ไม่ใช้ชื่อที่ผู้ใช้ส่งมา
- อ่านรูปได้เฉพาะคีย์รูปแบบ `gallery/<uuid>.jpg|png|webp` ที่ Worker เขียนเอง
- ตอบกลับพร้อม `X-Content-Type-Options: nosniff` และ `Content-Security-Policy: sandbox`

## ที่ยังไม่มี

- **ลบรูปออกจาก R2**: ตอนนี้ "ลบ" ในแกลเลอรี่เอารูปออกจากเซต แต่ไฟล์ยังอยู่ใน bucket (ไฟล์เล็ก ค่าเก็บแทบไม่มี) ถ้าต้องการล้างไฟล์ที่ไม่ได้ใช้ ทำจาก Dashboard หรือเพิ่มคำสั่งลบภายหลัง
