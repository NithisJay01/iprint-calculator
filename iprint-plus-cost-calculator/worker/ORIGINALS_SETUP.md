# ไฟล์ต้นฉบับขนาดใหญ่ (เกิน 10 MB) — เก็บใน R2 แล้วดึงลงเครื่องร้านทุกวันเสาร์

ลูกค้าอัปโหลดไฟล์งานได้ถึง **90 MB ต่อไฟล์** (PDF, PNG, JPG, WebP) หน้า Preview ใช้ภาพย่อดู แต่ตอนกดสั่งพิมพ์:

```
คำขอ (บรีฟ + PDF/SVG ขนาดย่อ)  → Worker → Notion            เหมือนเดิม
ไฟล์ต้นฉบับใหญ่ (แยกส่ง)        → Worker → R2 (incoming/)    ตั๋วอัปโหลดที่ Worker ออกให้หลังบันทึกคำขอ
ทุกวันเสาร์: สคริปต์บนเครื่องร้าน → ดึงจาก R2 → External drive → ลบจาก R2
```

ในบรีฟของ Notion จะมีบรรทัด "ไฟล์ต้นฉบับขนาดใหญ่: …" บอกว่างานนี้มีไฟล์ที่ต้องไปดึง
ไฟล์ที่ดึงลงเครื่องจะอยู่ที่ `<ปลายทาง>\<วันที่ดึง>\<ชื่อลูกค้า-ชื่องาน-รหัส>\front_<ชื่อไฟล์>` (ด้านหลังขึ้นต้นด้วย `back_`)

## ตั้งค่า (ครั้งเดียว)

1. **Deploy Worker** ใหม่ (ใช้ `MEDIA` bucket เดิมที่ตั้งไว้แล้ว ไม่ต้องสร้างอะไรเพิ่ม): `npx wrangler deploy`
2. **ตั้งให้ R2 ลบไฟล์ค้างเองใน 14 วัน** (กันลืมลบ และกันค่าใช้จ่าย) — ทำเฉพาะโฟลเดอร์ `incoming/` ไม่แตะรูปแกลเลอรี่:
   ```
   npx wrangler r2 bucket lifecycle add iprint-media --name expire-incoming --prefix incoming/ --expire-days 14
   ```
3. **ตั้งแจ้งเตือนค่าใช้จ่าย** ใน Cloudflare: Billing → Notifications → ตั้งเตือนเมื่อเกิน $1
4. บนเครื่องร้าน (ต้องมี Node.js 18 ขึ้นไป) ตั้ง Key พนักงานเป็นตัวแปรของ Windows ครั้งเดียว แล้วเปิดหน้าต่างใหม่:
   ```
   setx IPRINT_API_KEY "ใส่ API Key พนักงาน"
   setx IPRINT_DEST "E:\งานลูกค้า"
   ```
   (Key ห้ามใส่ในไฟล์ในโปรเจกต์หรือส่งในแชต)

## ทุกวันเสาร์

เสียบ External drive แล้วรัน (จากโฟลเดอร์โปรเจกต์ `iprint-calculator`):

```
node scripts/fetch-originals.mjs
```

ตัวเลือก: `--status` ดูว่ามีไฟล์ค้างกี่ไฟล์และ R2 เต็มแค่ไหน (ไม่ดึง ไม่ลบ) · `--dry-run` ดูรายการที่จะดึง · `--keep` ดึงแต่ไม่ลบจาก R2 · `--dest "D:\โฟลเดอร์"` เปลี่ยนปลายทาง

สิ่งที่สคริปต์ทำให้:
- **ไม่ลบอะไรจาก R2 จนกว่าจะคัดลอกครบและขนาดตรงกัน** ไฟล์ที่ผิดพลาดจะอยู่ใน R2 ต่อ และสคริปต์จะบอกว่าไฟล์ไหน (รันซ้ำได้ ไฟล์ที่ดึงแล้วจะไม่ถูกดึงซ้ำ)
- **ถ้าไม่ได้เสียบ External drive สคริปต์หยุดทันที** ไม่ดึงและไม่ลบอะไร (ไม่สร้างโฟลเดอร์ปลายทางเอง)
- ไม่มีสำเนาที่สอง: หลังลบจาก R2 ไฟล์จะอยู่ที่ External drive ที่เดียว ควรสำรองไดรฟ์นั้นไว้อีกที่

## พื้นที่ 10 GB (โควตาฟรีของ R2)

- ระบบ **หยุดรับไฟล์ต้นฉบับเมื่อไฟล์ค้างรวมถึง 10 GB** (ตั้งได้ด้วย `ORIGINALS_MAX_TOTAL_BYTES` ใน `wrangler.toml` [vars]) ลูกค้าจะเห็นข้อความให้ส่งไฟล์ทาง LINE แทน — R2 จึงไม่มีทางเกินโควตาฟรีจากไฟล์กลุ่มนี้
- เมื่อใช้เกิน 80% สคริปต์จะขึ้นคำเตือนตอนรัน (`--status` ก็เห็น) ให้ดึงไฟล์ลงเครื่องเร็วขึ้น
- ยังไม่มีการแจ้งเตือนแบบส่งเข้า LINE/อีเมลโดยอัตโนมัติ ต้องรันสคริปต์ (หรือ `--status`) ถึงจะเห็น

## กฎที่ระบบบังคับ

- อัปโหลดได้ต่อเมื่อส่งคำขอผ่านการตรวจ Turnstile แล้ว: Worker ออก "ตั๋ว" ที่เซ็นชื่อกำกับ อายุ 24 ชั่วโมง ระบุด้าน (หน้า/หลัง) ชื่อ และขนาดไฟล์ที่แจ้งไว้ในคำขอเท่านั้น
- ขนาดไฟล์ที่ส่งมาต้องตรงกับที่แจ้ง และไม่เกิน 90 MB ต่อไฟล์
- รับเฉพาะ PDF, PNG, JPG, WebP, SVG ตรวจจากไบต์แรกของไฟล์หลังเขียน ถ้าไม่ใช่จะลบทิ้งทันที
- ชื่อไฟล์ใน R2 ผ่านการล้างอักขระ ไม่มี `..` หรือเครื่องหมายเส้นทาง
- ดู/ดาวน์โหลด/ลบไฟล์ได้เฉพาะพนักงานที่มี `X-API-Key` (`/staff/originals`) ไม่มีลิงก์สาธารณะ ไฟล์ลูกค้าเปิดจากภายนอกไม่ได้

## ที่ยังไม่มี

- ไฟล์ Layer 3 (เทคนิคพิเศษ) และไฟล์ไดคัทส่งเป็นไฟล์ในคำขอเท่านั้น (ไม่เกิน 10 MB)
- ถ้า R2 ยังไม่ได้ตั้งค่า คำขอยังส่งได้ปกติ แต่ไฟล์ต้นฉบับที่ใหญ่จะไม่ถูกอัปโหลด หน้าเว็บจะแจ้งลูกค้าให้ส่งไฟล์ทาง LINE
