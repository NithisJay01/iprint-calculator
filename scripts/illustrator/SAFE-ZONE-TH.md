# Safe Zone 3 มม. — 2 คำสั่งสำหรับ Illustrator

## 1. สร้างไกด์

รัน `01_CreateSafeZone3mm.jsx` เพื่อสร้างกรอบ Guide เข้ามาจาก Artboard ที่กำลังใช้งาน 3 มม. ทุกด้าน อยู่ในเลเยอร์ `iPrint Safe Zone 3mm` ซึ่งล็อกและไม่พิมพ์ออก รันซ้ำจะปรับไกด์เดิมของหมายเลข Artboard นั้น หากไม่เห็นเส้น ให้เปิด View > Guides > Show Guides

หากลบหรือจัดลำดับ Artboard ใหม่ ให้ลบเลเยอร์ไกด์นี้แล้วรันสร้างใหม่ตาม Artboard ที่ต้องการ

## 2. ย้ายวัตถุเข้าชิด Safe Zone ที่ใกล้ที่สุด

เลือก Artboard เป้าหมาย แล้วใช้ Selection Tool (V) เลือกวัตถุทั้งชิ้น จากนั้นรัน `02_MoveToNearestSafeZone.jsx`

- ย้ายจนขอบวัตถุชิดเส้น Safe Zone ด้านที่ใช้ระยะเคลื่อนที่สั้นที่สุด และวัตถุทั้งชิ้นอยู่ภายในพื้นที่ปลอดภัย
- วัตถุที่อยู่ภายในอยู่แล้วจะถูกย้ายไปชิดด้านใกล้ที่สุดด้วย หากระยะเท่ากันจะเลือกซ้าย ขวา บน ล่าง ตามลำดับ
- วัตถุที่อยู่นอกมุมอาจย้ายทั้งแนวนอนและแนวตั้งเพื่อให้เข้าพื้นที่ทั้งหมด
- เลือกหลายชิ้นจะย้ายเป็นชุดเดียว รักษาระยะระหว่างวัตถุ ไม่แยกแต่ละชิ้นไปคนละด้าน
- คำนวณจากขอบรวม Stroke; Clipping Group ใช้ขอบกรอบของ Clipping Path ไม่ใช่ภาพที่ซ่อนอยู่นอกกรอบ เอฟเฟ็กต์ซับซ้อนหรือเงาควรตรวจด้วยตาหลังย้าย
- ถ้าใหญ่กว่าพื้นที่ Safe Zone จะหยุดพร้อมแจ้งเตือน ไม่ย่อหรือครอปงาน
- ใช้ Artboard ปัจจุบันเสมอ ไม่เดา Artboard จากตำแหน่งวัตถุ และไม่จำเป็นต้องรันคำสั่งแรกก่อน

## รันและเรียกใช้เร็ว

ใช้ File > Scripts > Other Script… แล้วเลือกไฟล์ `.jsx` ที่ต้องการ ทั้งสองไฟล์เป็นสคริปต์แยกอิสระ ไม่มีหน้าต่างตั้งค่าและไม่ต้องติดตั้งไฟล์เสริม

หากต้องการให้ปรากฏในเมนู Scripts ให้นำทั้งสองไฟล์ไปไว้ในโฟลเดอร์ Presets/<ภาษาของโปรแกรม>/Scripts ของ Illustrator แล้วเปิดโปรแกรมใหม่

สำหรับปุ่ม Action: เปิด Window > Actions สร้าง Action ใหม่ จากเมนูของแผงใช้ Insert Menu Item แล้วเลือกคำสั่งสคริปต์ที่ติดตั้งใน File > Scripts ถ้ารุ่นที่ใช้อยู่รองรับการเรียกสคริปต์ผ่าน Action สามารถผูกปุ่ม Function Key หรือเปิด Button Mode ได้ หากชื่อสคริปต์ไม่ปรากฏหรือ Action ไม่เล่น ให้ใช้เมนู Scripts โดยตรง ทั้งสองไฟล์นี้ไม่ใช่ไฟล์ Action `.aia`

ตรวจสอบ syntax และทดสอบพฤติกรรมกับ Illustrator API จำลองแล้ว ยังไม่ได้ทดสอบกับโปรแกรม Illustrator จริง
