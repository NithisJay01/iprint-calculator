# AutoBleed สำหรับ Adobe Illustrator

ใช้ขอบ Artboard เป็นขนาดตัดจริง สร้างไกด์ขนาดตัดและ Bleed รอบด้าน (เริ่มต้น 3 มม.) พร้อมมาร์กตัด 8 เส้น เลือก Artboard ปัจจุบันหรือทั้งหมดได้

## วิธีใช้

1. เปิดงานใน Illustrator ตั้ง Artboard เท่าขนาดหลังตัด และบันทึกไฟล์ .ai
2. ไปที่ **File > Scripts > Other Script…** แล้วเลือก `AutoBleed.jsx`
3. ใส่ Bleed ตามที่โรงพิมพ์กำหนด เช่น 3 มม. เลือกขอบเขต Artboard แล้วกด Run
4. ขยายพื้นหลังหรือภาพให้ถึงไกด์วงนอก หากไม่เห็นไกด์ ให้ใช้ View > Guides > Show Guides
5. เมื่องานพร้อมส่งพิมพ์ รันอีกครั้งและเลือก **Save as PDF** หรือบันทึก PDF เอง แล้วระบุ Bleed และ Trim Marks ในหมวด Marks and Bleeds

ตัวอย่าง: นามบัตร 90 × 54 มม. ใช้ Artboard 90 × 54 มม. เมื่อ Bleed 3 มม. ภาพพื้นหลังต้องครอบคลุม 96 × 60 มม.

## พฤติกรรมที่ควรรู้

- สคริปต์ไม่เปลี่ยนขนาด Artboard ไม่ยืดภาพ และไม่เติมพิกเซลส่วนที่ขาดให้โดยอัตโนมัติ
- ไกด์เป็นเส้นช่วยจัดงาน ไม่ใช่ค่า Bleed ใน Document Setup สคริปต์ตั้งค่า Bleed จริงเมื่อเลือกบันทึก PDF เท่านั้น
- PDF ใช้ Save As จึงเปลี่ยนเอกสารที่เปิดอยู่เป็นไฟล์ PDF ควรบันทึกต้นฉบับ .ai ก่อน หากจะแก้ต้นฉบับต่อให้เปิด .ai อีกครั้ง
- ไกด์ไม่พิมพ์ออก ส่วน PDF ใช้มาร์กตัดของ Illustrator และซ่อนเลเยอร์มาร์กที่สคริปต์สร้างชั่วคราวระหว่างบันทึก
- ทุกครั้งที่รันจะสร้างเลเยอร์ใหม่ หากรันซ้ำให้ลบเลเยอร์ AutoBleed เก่าที่ไม่ต้องการก่อน เพื่อไม่ให้ไกด์ซ้อนกัน
- สำหรับหลาย Artboard ควรเว้นช่องว่างให้ Bleed และมาร์กไม่ทับงานข้างเคียง
- ไม่ได้เลือกมาตรฐาน PDF/X หรือแปลงโปรไฟล์สีให้ ควรใช้ค่าตามโรงพิมพ์เมื่อจำเป็น
- UI เป็นภาษาอังกฤษเพื่อรองรับฟอนต์ของ ScriptUI ต่างรุ่น

## การตรวจสอบ

ตรวจสอบ syntax ของ JavaScript แล้ว แต่ยังไม่ได้รันทดสอบใน Illustrator จริงบนเครื่องนี้ ควรลองกับสำเนางานหนึ่ง Artboard และตรวจ PDF ก่อนใช้งานผลิตจริง
